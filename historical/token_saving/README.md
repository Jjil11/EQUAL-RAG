# Earlier non-RAG token-saving research

These are preceding code experiments concerning long/short post-training, answer-blind compact targets, within-question length controls, cross-model evaluation and serving replay. They explain the broader project's origin, but are not the current EQUAL-RAG method or final evidence.

No historical weights, private server scripts, datasets or manuscript drafts are included. Some commands depend on their original prepared assets and model stacks; machine paths have been made configurable, not fully re-engineered into a new SDK. Do not transfer their result claims to the later citation/coverage experiments.
