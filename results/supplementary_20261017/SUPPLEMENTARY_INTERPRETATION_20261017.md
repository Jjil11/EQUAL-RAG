# 补充实验结论与论文表述边界

状态：全部正式训练、推理、统计、传回和独立校验均已完成。本文件是解读附录，不替代原始预测、完整统计表或校验记录。完整主报告为项目根目录 `EQUAL_SUPPLEMENTARY_RESULTS_20261017.md`。

## 1. 关键结论：新基线改变了论文的证据边界

本轮没有证实 EQUAL 在引用覆盖 Q 上优于严格匹配的普通 SFT/DPO，也没有证实优于简单的穷举提示。不能为了维持原结论删除这些基线、改写评分函数、重新挑选 checkpoint 或继续用 311 题调参。

下面是 Qwen3-14B、固定主 Seed 20261015 的 Full311 单 Seed 结果，不是原主论文三 Seed 均值：

| 系统 | Q % | Full F1 % | 平均 Token | 重复率 % | 真触顶率 % | 新增/丢失/净增支持引用组 |
|---|---:|---:|---:|---:|---:|---:|
| Base | 51.86 | 12.40 | 26.23 | 4.18 | 0.00 | 0/0/0 |
| EQUAL CE β=0 | 57.44 | 13.34 | 29.54 | 5.14 | 0.00 | 37/10/+27 |
| EQUAL AOnly β=0.25 | 60.33 | 13.78 | 31.17 | 6.43 | 0.32 | 51/10/+41 |
| EQUAL AOnly β=0.50 | 60.74 | 13.60 | 30.53 | 6.43 | 0.00 | 54/11/+43 |
| Exhaustive Prompt | 70.45 | 12.68 | 40.67 | 5.47 | 0.00 | 107/17/+90 |
| Matched Whole-Answer SFT | 65.91 | 13.76 | 35.49 | 8.04 | 0.32 | 78/10/+68 |
| Matched Sequence DPO + 0.1 SFT | 65.70 | 13.75 | 38.21 | 8.36 | 0.32 | 81/14/+67 |

EQUAL β=0.25 相对三个新基线的 20,000 次问题级配对 Bootstrap 差值如下。单位为百分点；均为未作多重比较校正的名义 95% 区间。

| 比较 | ΔQ [95% CI] | ΔFull F1 [95% CI] |
|---|---:|---:|
| EQUAL − Exhaustive Prompt | −10.12 [−19.69, −1.12] | +1.10 [−0.02, +2.24] |
| EQUAL − Matched SFT | −5.58 [−12.79, −0.70] | +0.02 [−0.76, +0.73] |
| EQUAL − Matched DPO | −5.37 [−12.74, −0.39] | +0.03 [−0.79, +0.78] |

应如何理解：

- EQUAL 相对未训练 Base 的改进仍存在；但这是一个较弱的比较，不能推出优于强提示或相同目标答案上的标准训练。
- 三个新基线的 Q 均更高；上述三个 ΔQ 区间也都低于 0。不能声称 EQUAL 的覆盖优势得到了本轮验证。
- EQUAL 更短，是可以如实描述的长度—覆盖权衡；不能把“更短”直接当成综合性能显著更好。它对三个新基线的 Full F1 差值区间都包含 0；这既不证明显著更优，也不构成预注册的等效性或非劣效性检验。
- Matched SFT 与 EQUAL β=0.25 都丢失 10 组旧答案，SFT 的新增更多。不能声称这里的标准 SFT 因更大的旧答案损失而失败。
- EQUAL β=0.25 的 Full311 重复率高于 Base 与穷举提示，并存在 1 题真触顶；不能把开发集上的零重复/零触顶推广为全测试集保证。

切片结果并非处处相同：Raw24 上 Base/CE/AOnly/SFT/穷举提示均为 87.50% Q，CE/AOnly 更短且重复率低于 SFT；DPO 为 75.00%。Sparse226 上 CE 与匹配 SFT 均为 48.21% Q，CE 的长度为 23.62 vs 28.28 tokens、重复率为 6.19% vs 9.29%。这些是可报告的紧凑性/切片权衡，但 Raw24 总共只有 8 个支持组，Sparse226 也只有 56 个，必须连同完整区间报告，不能从点估计相近推导统计等效或全面优势。

## 2. BPE 审计能说明什么，不能说明什么

已检查的七个命名 tokenizer/encoding 均在 21/21 条 A 类记录上出现“分开编码后拼接”与“整段联合编码”不一致；重复的本地 Mistral 副本不计作另一个家族，Qwen2.5/Qwen3 也不是独立 tokenizer 家族。

| Tokenizer/encoding | 单独编码 `]` | 单独编码 `],` | 单独编码 `], ` | 存在不同的合并续写 token | 不匹配记录 |
|---|---|---|---|---|---:|
| Qwen3-14B | [60] | [1125] | [1125,220] | 是 | 21/21 |
| Qwen2.5-7B-Instruct | [60] | [1125] | [1125,220] | 是 | 21/21 |
| Mistral-7B-Instruct-v0.3 | [5477] | [12820] | [12820,29473] | 是 | 21/21 |
| Phi-3-mini-4k-instruct | [4514] | [21251] | [21251,29871] | 是 | 21/21 |
| GPT-2 | [60] | [4357] | [4357,220] | 是 | 21/21 |
| cl100k_base | [60] | [1145] | [1145,220] | 是 | 21/21 |
| o200k_base | [60] | [2155] | [2155,220] | 是 | 21/21 |

单独编码的 ID 不一定等于完整上下文里的 ID。例如本次 Mistral 示例在引用数字后的原生右括号为 29561，续写边界首个变化 token 为 1949；最终修复使用实际上下文，而不是将上表里的独立 token ID 硬填到模型中。完整 21 条逐例 ID 窗口与 tokenizer 配置 SHA 已归档。

这支持一个跨多种分词器的实现注意事项：局部轨迹修复需要检查边界分词一致性。但它不证明模型在裸 `]` 后数学上无法继续，不证明所有模型都有相同的概率障碍，也不证明联合重分词本身是一种优于标准整答案 SFT 的新优化算法。整答案 SFT 本来就使用完整正答案的联合 token 序列。

穷举提示无需训练就获得很高的 Q，也说明不能把“默认提示下容易早停”写成“仅靠训练才能解锁的普遍硬死锁”。Llama3/Gemma 的不可用或受限记录不是反例，也不是通过项。

## 3. 第二骨干：相对 Base 复现收益，不代表优于匹配 SFT

已固定 Mistral-7B-Instruct-v0.3，revision `c170c708c41dac9275d15a8fff4eca08d52bab71`。350 条原生训练轨迹编译出 A=15、嵌入式 C1=15、C2=10，保留轨迹 120 条、5,317 个位置。没有为凑到 Qwen 的样本数补造标签。

Full311 结果如下：

| 系统 | Q % | Full F1 % | 平均 Token | 重复率 % | 真触顶率 % | 新增/丢失/净增支持引用组 |
|---|---:|---:|---:|---:|---:|---:|
| Mistral Base | 37.81 | 8.99 | 46.91 | 2.25 | 0.64 | 0/0/0 |
| Matched Whole-Answer SFT | 52.48 | 12.03 | 49.16 | 8.04 | 0.96 | 90/19/+71 |
| EQUAL CE β=0 | 40.29 | 9.87 | 43.42 | 2.57 | 0.32 | 26/14/+12 |
| EQUAL AOnly β=0.25 | 45.25 | 10.89 | 47.22 | 3.22 | 0.00 | 47/11/+36 |

| 比较 | ΔQ [95% CI]，百分点 | ΔFull F1 [95% CI]，百分点 |
|---|---:|---:|
| CE − Base | +2.48 [−0.76, +5.85] | +0.87 [−0.03, +1.80] |
| AOnly − Base | +7.44 [+2.28, +13.49] | +1.89 [+1.03, +2.83] |
| CE − SFT | −12.19 [−20.04, −5.13] | −2.16 [−3.31, −1.08] |
| AOnly − SFT | −7.23 [−16.17, +1.41] | −1.14 [−2.26, −0.06] |

可支持的结论是：带 A-Only Hinge 的版本不只在 Qwen 上有效，在另一个家族的 Mistral 上，相对未训练 Base 的 Q 与 F1 也有名义显著提升。纯 CE 修复相对 Base 的这两个区间都跨 0，不能一并称为显著复现。

不能支持的结论是：EQUAL 全面胜过标准 SFT。Mistral 上 AOnly 的 Q 点估计低于 SFT，但该差值区间跨 0；F1 差值区间低于 0。与此同时，AOnly 丢失的支持引用组较少（11 vs 19）、重复/触顶更少，但新增也较少（47 vs 90）。其中 AOnly 的新增为真新名字带支持引用 41 组、原名字引用修复 6 组；SFT 分别为 68/22 组。这仍是保留性、召回与输出行为的权衡，不是全面优势。

两个骨干使用各自原生标签，监督记录数分别为 41 和 25；不能把它们之间的得分差异完全归因为模型规模或 tokenizer。所有比较都应连同原生标签规模与单 Seed 限定报告。

训练诊断：Mistral AOnly 的 A 首动作 15/15、首个新实体逐 token 命中 12/15、C1=15/15、C2=10/10；CE 相应为 13/15、12/15、15/15、10/10；SFT 为 15/15、14/15、15/15、10/10。训练侧学会目标不是测试侧领先的充分条件。

前缀保留指标也确实体现了机制差异：Qwen 的 CE/AOnly0.25/AOnly0.50 分别为 93/120、89/120、91/120，匹配 SFT/DPO 为 53/120、30/120；Mistral 的 CE/AOnly 为 81/120、73/120，SFT 为 28/120。但更高的 teacher-forced 保留率没有转化为更高的端到端 Q，也不保证更少的测试组丢失。这个区别必须在论文中说明。

## 4. 投稿时必须保留的限定

- 311 题已经在主实验中解封；新基线和第二骨干是解封后的补充评测，不是另一轮独立盲测。
- 新基线和 Mistral 只有一个训练 Seed，不应冒充新增三 Seed 稳定性证据。
- 匹配的是 60 次更新和 240 次监督记录访问；EQUAL 另有 240 次辅助保留访问，因此不等于 FLOPs、训练 Token 数或壁钟时间完全匹配。
- DPO 是明确报告的 β=0.1、序列 log-prob 求和、0.1 SFT 稳定项；C2 相同正负对没有人工偏好梯度。不能把它标作另一个未实际运行的纯 DPO 版本。
- 保留轨迹 top-1 一致率是 teacher-forced 诊断，不是端到端正确性、完备性或“旧答案绝不丢失”的保证。
- 本轮观测到 GPU 温度/频率差异，未调整服务器设置；不得用本次壁钟时间证明算法效率优越。详见 `HARDWARE_NOTES.md`。

如果论文现有表述是“EQUAL 优于匹配 SFT/DPO/强提示”“BPE 普遍不可继续”“在所有切片都减少重复且无触顶”，本轮数据不支持这些措辞，应修改。旧 Anchor 对照仍有诊断价值，但不足以单独证明相对标准训练的算法优势。
